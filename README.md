## 🛠 技術・実装メモ

### 1. バトルロジック (`BattleManager` クラス)
`js/main.js` に実装。ゲームの状態を管理するシングルトン的な役割。
- `drawPile` (山札配列)
- `hand` (手札配列)
- `discardPile` (捨て札配列)
- `initBattle()`: 戦闘開始時の初期化
- `drawCard(n)`: 山札からn枚引く。山札不足時は捨て札をリシャッフル。
- `endTurn()`: HTMLボタンからトリガー。手札を全て捨てて、次のターンへ。

### 2. カードデータの追加
